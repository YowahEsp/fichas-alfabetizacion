# fichas-alfabetizacion
Fichas de lecto-escritura para EPA según la progresión del método Palau

## Herramientas

- `herramientas/construir_memimaM.py`, `herramientas/zeta.py`: reconstrucción de las fuentes (solo si hiciera falta rehacerlas).
- `herramientas/crucigramas/`: generador, montaje y auditor de las cruzadas con pictogramas. Ver su `README.md`.
